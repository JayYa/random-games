# 先决定结果，再反算旋转角度

一次转动先用一次 `random()` 选出中选饭店，再反算转盘需要旋转多少度才能让它停在顶部指针处（约 5~8 圈 + 3.5 秒 easeOutCubic）。替代方案是给转盘一个随机初速度、让它"物理地"停下来，结果由摩擦模拟决定。

选前者是因为随机性从此集中在一行代码里，其余全是确定性动画：结果可复现、可单元测试（选中项 → 目标角度的反算是这个项目唯一会算错且肉眼极难发现的地方），也可以向人解释清楚。代价是转盘的物理感是假的。

## Consequences

因此**不支持手指甩动来转**。甩动会暗示手势力度能影响结果，而结果在手指离开屏幕前就已经定好了，两者互相矛盾——只提供一个大按钮。另外落点取扇区内的随机位置而非正中，否则每次都停得过于整齐，反而显得像假的。
