# 转盘先定停在哪个扇区，再反算旋转角度

转一次先用一次 `random()` 定下停在哪个扇区（扇区内取随机位置，不停正中），再反算要转多少度才让它停在指针下。备选是给一个随机初速度、靠摩擦模拟"物理地"停下。选前者是因为随机性集中在一行，其余全是确定性动画，可复现、可单元测试；代价是转盘的物理感是假的。停在哪个扇区只决定名字亮在哪儿，不决定谁中选（[ADR-0010](./0010-board-is-a-show-winner-drawn-after.md)）。

## Consequences

- **不支持手指甩动来转**，只给一个按钮：甩动暗示力度能影响落点，而落点在手指离开屏幕前就定好了。
- **反算算错肉眼看不出来**，所以由一条端到端用例守着不变量：转盘停下之后，指针底下的扇区就是先定下的那一个。扇区与角度的换算只在一处实现。
- 弹球机反过来由物理决定落格，见 [ADR-0006](./0006-pinball-slot-is-decided-by-physics.md)。
