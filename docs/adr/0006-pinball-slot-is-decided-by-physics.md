# 弹球机的落格由物理决定

转盘先定落点再反算动画（[ADR-0003](./0003-result-first-animation-second.md)），弹球机刻意反过来：球落进哪个落格由实际撞出来的轨迹决定，没人预先选好。弹球机存在的意义是参与感，力度和发射时机必须真的决定落格。两条 ADR 是同一条原则——用户能操作的东西必须真的算数——在两种前提下的结论。落格只决定名字亮在哪儿，不决定谁中选（[ADR-0010](./0010-board-is-a-show-winner-drawn-after.md)）。

## Consequences

- **落格不追求等概率**，练出手感、偏好某几格都无害：落格不对应候选。钉阵和弹力柱把力度差异打散，不让它变成纯技巧。
- **物理是确定性的**：定步长，`(力度, 风车相位, 种子) → { 落格, 轨迹 }` 是纯函数，进单元测试（确定性的范围见 [ADR-0008](./0008-matter-js-over-hand-rolled-physics.md)）。
- **先跑完模拟，再回放轨迹**：发射瞬间跑完整段模拟，再按累积时间插值回放，高刷屏和掉帧都不改变球速。
- **卡住的兜底用户看不见**：超过步数上限就换种子重跑，重试用尽才判给最近的落格；模拟在回放之前，卡住的球永远不上屏。
- **进格即定**：球心越过隔板顶那一帧就判定。"停稳才定"会出现进了 3 号又跳到 4 号，名字该亮在哪一格说不清。
- **风车在发射前就在转**，相位可见，发射瞬间快照进模拟。发射后才启动的风车只是隐藏的随机数。
- **弹球机键盘不可达**：柱塞是拖拽加挑时机，暂不提供键盘等价操作。这是明知的代价，其余页面都刻意键盘可达。
