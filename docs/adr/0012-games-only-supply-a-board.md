# 玩法只交盘面，名单、开抽与结果卡片由玩法页宿主接

玩法记录不再带挂载函数，只带一个盘面：盘面交出自己的 HTML 和结果卡片按钮上的字，挂上之后只管画、演，在盘面停下时报一声，被叫到时把名字写上或抹掉。建名单会话、名单写坏时的错误页、结果卡片、开抽会话、「开抽之后盘面锁死」的判据和拆卸，统一由一个与玩法无关的玩法页宿主接好，路由取到名单原文之后只调它。

这是在做完 [ADR-0007](./0007-game-is-rolled-into-the-url.md) 已经定下的事：那里说取 CSV、错误页、页头、结果卡片都归共享，不属于任何一个玩法。原来的挂载函数把名单原文和最近中选整份交给玩法，于是每个玩法都自己接了一遍，两份接线也已经走岔：一边用 `isRollLocked` 判锁，另一边直接比较开抽阶段。

## Considered Options

- **玩法照旧是入口，在挂载函数里先调宿主**：改动小，但「先调宿主、按什么顺序」还是每个玩法各自记着，下一个玩法照样能漏写、写岔。
- **把开抽会话整个交给盘面**：盘面就能读到开抽阶段，判锁又能绕开那一句判据。盘面拿到的是一个开抽句柄，上面只有「开抽」「盘面停下」和「锁没锁」。

## Consequences

- **盘面拿不到名单**：不知道有几个候选，也不知道最近中选；从接口上钉住 [ADR-0010](./0010-board-is-a-show-winner-drawn-after.md) 的「盘面只是表演」。
- **停在哪一格仍是盘面自己的事**：宿主只叫盘面揭晓这个中选，不转手格子下标，格数也就继续只有盘面自己知道。
- **宿主是无头的**：写页面、建卡片都经一个注入的页面适配器，用例拿假页面和假盘面跑，不引入 DOM 测试环境。
- **取名单、加载态与「取不到文件」的错误页仍在路由**：晚回来的名单不上屏是导航的规则，不归宿主。
- 加一个玩法 = 往玩法清单里加一条 slug 加盘面的记录，不再接任何会话。
