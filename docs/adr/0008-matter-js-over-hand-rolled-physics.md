# 用 matter.js，放弃跨环境的确定性

弹球机的物理用 matter.js（只用 Engine，固定步长手动步进），这是仓库唯一的运行时依赖。手写两三百行也可行，还能把浮点行为攥在手里；选库是因为弹球机不会是最后一个玩法，选型按"下一个玩法好不好写"判断。

## Consequences

- **确定性降级**：matter.js 的浮点结果不保证跨浏览器、跨机器一致，[ADR-0006](./0006-pinball-slot-is-decided-by-physics.md) 的确定性只承诺"同一运行环境内，同样输入必得同样落格"。单元测试（CI 是固定环境）和产品（没人需要复现别人那一发）都够用。
- **必须关掉 sleeping、绕开引擎自己的时间步**，否则同样输入不再必得同样结果。
- **物理参数集中在一张常量表里**，调参不用翻代码。
- **靠分布冒烟测试兜底**：两百发覆盖全部力度区间，断言每个落格至少中一次，防钉阵摆得让某格永远打不中。不做卡方检验：落格本就不追求等概率，没有该过的基线。
