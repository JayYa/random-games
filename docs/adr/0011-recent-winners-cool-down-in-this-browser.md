# 最近的中选和玩法在这台浏览器里冷却

纯等概率会让连着几天抽出同一个候选。因此每个主题在浏览器的 localStorage 里记下最近 7 次中选，它们冷却、不参与抽取；抽玩法同理，记最近 1 次玩法。两边同一套规则，只是次数不同：玩法种类少，冷却多了就退化成固定顺序轮流。localStorage 是不引入服务器的唯一选择（[ADR-0001](./0001-csv-in-repo-no-backend.md)）。

## Considered Options

- **CSV 加权重列**：只能压低整体频率，治不了"刚抽过又抽到"。
- **按时间窗口冷却**：隔一阵子没开就全部解冷或全部还冷着，不如按次数好推理。
- **降权而非排除**：最近抽过的仍可能再中，"不能一样"做不到。
- **只记用户最终采纳的那个**：站点不知道用户采纳了哪个；被"再抽一次"甩掉的本来就是最近不想要的。

## Consequences

- **冷却对用户不可见**：不显示历史，不给清空按钮。
- **记忆各浏览器一份**：换设备、无痕、清数据就从头来；存储不可用或读出坏数据时静默退化为没有记忆。
- **可抽的永远至少一个**：冷却个数取 `min(N, 可抽总数 − 1)`，最早的先解冷。可抽总数就是候选数，写重的名字在名单里已合成一个候选。
- **名字亮出的那一刻就记**，不等用户收下，否则关页重开就能反复刷同一个。按名字记，改名、删除或停用的名字照旧占一格，几次后自然挤出去。
- **最近中选按主题分，最近玩法全站一份**。只有真正抽出来的玩法才记；直接打开带玩法的地址不算。
- **站点仍不记住上次选的主题**（[ADR-0005](./0005-one-csv-per-theme.md)）：记中选是为了抽得好，记主题则是替人做选择。
