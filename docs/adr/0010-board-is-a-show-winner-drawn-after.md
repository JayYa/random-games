# 盘面只是表演，中选在盘面停下之后才抽

开抽前把候选摆上盘面，结果没出来用户就看过了全部可能，期待感就没了。因此盘面是匿名的：扇区和落格只有颜色，不对应候选。盘面停下之后，才从启用且不在冷却中的候选里等概率抽出中选，再把名字揭晓在停下的那一格上。名字既然藏起来，"每格对应一个候选"在统计上就和"停下再抽"等价，不如彻底拆开：盘面只管表演，中选只是一次等概率抽取。

## Consequences

- **没有"上盘"**：不抽一批候选摆上盘面，也就没有"换一批"；每个可抽的候选每次机会均等。
- **参与感只算数到落格为止**（[ADR-0003](./0003-result-first-animation-second.md)、[ADR-0006](./0006-pinball-slot-is-decided-by-physics.md)）。名字不可见，落点与候选的任何绑定都没法被利用，所以这不削弱参与感。
- **格数是盘面自己的常量**，与名单大小无关，页面也不以任何文案透露候选有几个：格数跟着候选数走就泄露了池子大小。
- **揭晓有一拍停顿**：名字亮出约 0.8 秒后才弹结果卡片（它是全屏遮罩，否则名字刚写上就被盖住），停顿期间盘面仍锁着。弹球机的落格写不下名字，名字浮在那一格上方。
- **只剩一个可抽候选时照常表演**，不做特殊处理。
