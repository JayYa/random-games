# 盘面只是表演，中选在盘面停下之后才抽

开抽之前如果把候选都摆在盘面上，结果还没出来用户已经看过了全部可能，期待感就没了。因此**盘面是匿名的**：扇区和落格只有颜色，不对应任何候选。盘面停下之后，才从名单中启用且不在冷却中的候选里等概率抽出中选，再把名字**揭晓**在停下的那一格上。

名字藏起来之后，"每一格对应一个候选"就只剩一个名头：这个对应关系用户看不见，只要它是均匀随机的，统计上就和"停下之后再抽"完全等价——用户本来就瞄不准任何一个候选。既然如此，不如把两件事彻底拆开：盘面只管表演，中选只有一行等概率抽取。

## Consequences

- **没有"上盘"这回事**：不从名单里抽样出一批候选摆上盘面，也就没有"换一批"。每个不在冷却中的启用候选每次开抽的机会都均等，不会有候选因为没被抽上盘而这一轮完全没机会。
- **弹球机的力度和时机只算数到落格为止**（[ADR-0006](./0006-pinball-slot-is-decided-by-physics.md)），转盘先定的也只是停在哪个扇区（[ADR-0003](./0003-result-first-animation-second.md)）。名字不可见时，落点与候选的任何绑定都没法被用户利用，所以这不是在削弱参与感。
- **格数是盘面自己的常量**（转盘 12，弹球机 8），与名单大小无关。格数要是跟着启用候选的个数走，盘面的形状就把候选数量泄露出去了。页面也不以任何文案透露池子有多大。
- **揭晓有一拍停顿**：盘面停下、名字亮出，约 0.8 秒后才弹结果卡片。卡片是全屏遮罩，没有这一拍名字刚写上就被盖住了。停顿期间盘面仍然锁着。收下中选时名字随之抹掉，盘面回到匿名。弹球机的落格太窄写不下名字，名字浮在那一格上方，可以超出格宽。
- **只剩一个启用候选时照常表演**，不做特殊处理。
