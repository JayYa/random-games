# 上盘名单是打乱后的前若干个，上限由玩法决定

盘面画不下太多候选：40 个扇区的转盘字挤成一团、扇区细如发丝，可读性崩溃。因此上盘名单有上限，而**上限是玩法的属性，不是一个全站常数**——转盘 12 个扇区，弹球机 8 个落格（一排落格横向排开，8 个已是极限，见 [ADR-0006](./0006-pinball-is-arbitrated-by-physics.md)）。取上盘名单只有一条路径：把名单中启用的候选整体打乱，取前 N 个，N 是当前玩法的上限。启用的候选超过上限时这就是随机抽样，界面上明确标注"已从 N 个中随机选出 M 个"；不超过时全部上盘，只是座次被打乱了。

打乱是刻意的，不只是抽样的副产品。CSV 里的书写顺序通常带着人的偏好（想吃的写在前面）或历史（新加的追加在末尾），照搬到盘面上会让相邻扇区、扇区配色每次都一模一样，看久了像是摆好的。打乱只改变谁挨着谁、谁是什么颜色，不影响谁中选。

## Consequences

抽样牺牲了"每个候选机会均等"的直觉——没被抽进上盘名单的这一轮完全没有机会。为此有两条硬性约束：

- **抽样必须发生在用户看到盘面之前**，进玩法页时抽一次并固定住。绝不能在用户开摇之后偷换盘面内容，那会让人觉得自己看中的候选凭空消失了。
- **启用的候选超过上限时必须提供"换一批"按钮**。否则用户看到一批不合心意的上盘名单时无路可走，只能刷新页面。换一批只能在开摇之前按：转盘转起来之后、弹球机发射之后，盘面就锁死了。

反过来，**不超过上限时不提供"换一批"**：候选一个没变，按下去只会换座次，与按钮上的字不符。想换个座次，刷新页面即可。

同一个主题在两种玩法下能看到的候选数不同（12 对 8），这是可以接受的：上限从来就是可读性逼出来的数字，不是一个概念。
